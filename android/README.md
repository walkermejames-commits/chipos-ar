# Android app — Caption Lens

Gradle project for the first ChipOS AR APK.

Open this `android/` folder in Android Studio, or build from a Windows command prompt:

```bat
gradlew.bat assembleDebug
gradlew.bat installDebug
```

Full Windows PC + phone + glasses steps: repository root `README.md`.

Hardware limits and the official XREAL Unity SDK path: `docs/HARDWARE_CAPABILITIES.md`.

First glasses-on checklist: `docs/PHASE_1_TEST_PLAN.md`.
